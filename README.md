# Project Homelab Establishment

Personal home server project -- digitizing a DVD collection and self-hosting media, built as a hands-on way to learn Linux, networking fundamentals.

# Architecture

[Router] -- [Switch] -- Tower PC / ThinkPad X230 / Dell Wyse 5070 Server


The server will run headless - no monitor or keyboard attached, will be controlled entirely over SSH.


# Status

Done: Ubuntu Server, SSH, static IP, storage amount, Jellyfin, Samba

Work in progress: Immich (photos), Tailscale (remote access outside home network)


## Disclaminer

This is a progress documentation, not meant to be a tutorial --entries reflect my understanding at the time, including things I got wrong and learnt.
